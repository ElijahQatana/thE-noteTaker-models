# thE-noteTaker models

Pre-converted model weights used by [thE-noteTaker](https://github.com/ElijahQatana/thE-noteTaker)'s first-run model setup.

See the [models-v1 release](../../releases/tag/models-v1) for downloadable assets. Converted from NVIDIA's `parakeet-tdt-0.6b-v3` and `diar_streaming_sortformer_4spk-v2.1` NeMo checkpoints (both on HuggingFace) using [parakeet.cpp](https://github.com/Frikallo/parakeet.cpp)'s `convert_nemo.py`. This repo only redistributes the converted weights for direct use by the app; it does not modify the underlying model.
